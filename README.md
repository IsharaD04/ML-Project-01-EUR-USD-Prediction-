# EUR/USD Exchange Rate Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on predicting the EUR/USD exchange rate using Machine Learning techniques. The model uses the K-Nearest Neighbors (KNN) Regression algorithm to learn patterns from historical EUR/USD exchange rate data and make predictions.

## 🎯 Objectives

- Analyze historical EUR/USD exchange rate data.
- Apply Machine Learning techniques for currency price prediction.
- Train a KNN Regression model.
- Evaluate model performance.
- Visualize actual and predicted exchange rates.

## 🛠️ Technologies & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 🤖 Machine Learning Algorithm

**K-Nearest Neighbors (KNN) Regression**

The KNN Regression algorithm predicts exchange rates by identifying the nearest data points based on feature similarity.

## ⚙️ Installation

Clone this repository:

```bash
git clone https://github.com/IsharaD04/ML-Project-01-EUR-USD-Prediction-.git
```

Navigate to the project folder:

```bash
cd ML-Project-01-EUR-USD-Prediction-
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the Python script:

```bash
python eur_usd_predict.py
```

The model performance can be evaluated by comparing predicted exchange rates with actual exchange rates using suitable regression evaluation metrics.
